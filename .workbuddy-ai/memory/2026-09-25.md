### 验证（headless Chrome）
- `npm run build` 通过（CSS 32.11kB）。
- 溢出审计：iframe 逐档 320/360/390/414/480/560/640/768/900/1024/1280 → `scrollWidth==clientWidth`，**0 溢出**。
  注意：`--window-size=390` 在 headless 下视口被钳到 500，**窄屏必须用 iframe 测，不能直接设 window-size**。
- 吸顶收窄实测：`.scrolled` 后 `navH 68→56`、头像 `34→28`、字号 `17→14`。
  注意坑（与 09-24 相同）：**`--dump-dom` 下 CSS transition 不推进**，必须先注入
  `*{transition:none!important}` 再量，否则会误判为"没收窄"；另外虚拟时钟下原生 scroll 事件
  不派发，需手动 `window.dispatchEvent(new Event('scroll'))`。

  需要浅色时先走 `localStorage.theme=light` 再跳转。
