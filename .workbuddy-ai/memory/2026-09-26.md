## 环境注意

- 仓库原本没有 node_modules；`npm install` 时 esbuild/rollup 的 Windows 原生包安装失败（EBUSY），
  且 npm 的 cleanup 被沙箱拦截 → 需手动补 `@esbuild/win32-x64`、`@rollup/rollup-win32-x64-msvc`。
- `npm run build` 会在清空 `dist/` 时被沙箱 bulk-delete 拦截（>50 文件）；
  绕法：`node node_modules/vite/bin/vite.js build --outDir 别的目录 --emptyOutDir`。
- 校验方式（无 build 时也能用）：用 `@vue/compiler-sfc` 的 `compileScript({inlineTemplate:true})` 编译各 SFC，
  再用 `vue/server-renderer` 做 SSR 渲染核对内容；postcss 解析 main.css 查语法。
- 遗留未清理（删除被沙箱拦截，下个回合可再删）：`smoke/`、`smoke-dist/`、
  `vite.config.js.timestamp-*.mjs`、`.pnpm-store/`；`package-lock.json` 曾被误删，已用 git 恢复。
