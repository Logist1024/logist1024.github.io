## 按钮质感修正

之前主按钮三个怪点：
1. 渐变亮端 `#9333ea` 偏品红，不够"星光紫"
2. hover 时 `background: var(--accent-hover)` 覆盖渐变 → 渐变消失、跳变
3. 描边按钮边框 `#ddd0fa` 在白底上几乎不可见，像"裸文字"

新增按钮专用令牌（不影响其他元素的 `--accent-gradient`）：
- `--btn-fill-a / --btn-fill-b`：深紫→更深紫（`#7c3aed → #5b21b6`），去掉了偏粉的 `#9333ea`
- `--btn-highlight` / `--btn-edge`：白色光泽与内描边
- `--btn-outline-bg / --btn-outline-bg-hover / --btn-outline-border / --btn-outline-border-hover`：描边按钮的可见紫边 + 极淡紫白底

`.btn-primary` 改用**双层背景**：`linear-gradient(180deg, 顶部白色光泽) + linear-gradient(135deg, 主色渐变)`，叠 `inset 0 0 0 1px` 内描边与外阴影，造出"3D 宝石光泽"质感——星野爱神秘闪耀感。
`.btn-primary:hover/active` 保持渐变（只换端点），加 `translateY(-1px)` 上浮，永远不再跳变成纯色。
`.btn-secondary` 底色从 transparent 改为 `#fbf9ff`，边框 `#c4b5fd`（清晰可见），加 `inset 0 1px 0 rgba(255,255,255,.5)` 顶部白色高光让按钮有"凸起感"——星野露比轻盈明亮感。

深色模式对应调整：主按钮用浅薰衣草 `#a78bfa → #c4b5fd`，描边按钮底色 `#1c1730`、边框 `#453568`。

1x 截图复核：主按钮现在有明显的上半亮/下半深的 3D 凸起感，描边按钮边框清晰、与实心按钮视觉重量协调。

## 修复 navbar 在深色模式下的"白条"硬编码 bug

上一版给 navbar 背景写了硬编码的浅色半透明白色 `rgba(253,251,255,.92)` 与 `rgba(248,245,255,.88)`，且没有 `[data-theme='dark']` 覆盖。结果深色模式下顶部栏是半透明白条浮在深紫黑页面上，极其突兀；同时深色下按钮的 `--btn-highlight: rgba(255,255,255,.28)` 把浅紫按钮冲淡成"发白的块"。

修法（仍只改 main.css）：
- 新增 `--nav-bg-top / --nav-bg-bottom / --nav-bg-top-scrolled / --nav-bg-bottom-scrolled / --nav-blur` 令牌，明暗各一套。
- 浅色：`#fdfbff` 0.92 → 0.72；`blur(14px) saturate(140%)`。
- 深色：`#131020` 0.92 → 0.72；`blur(14px) saturate(120%)`（深色下 saturate 太高会发亮发艳）。
- `.btn-primary` 深色态把 `--btn-highlight` 从 0.28 降到 0.12，`--btn-edge` 从 0.2 降到 0.08。

教训：**只要背景出现半透明白/黑，必须是 CSS 变量，明暗两套都得定义**，否则深色模式必然出 bug。

验证：临时写了一个 `dist/__dark.html`（内嵌 iframe 同源预置 localStorage theme=dark），用 chrome headless 截图，确认深色下顶部栏是深紫黑+淡紫光晕，主按钮仍是薰衣草紫（不再发白），整体协调。文件用完即删。
